# Protocolos científicos y compatibilidad

Para desarrollar o ejecutar el proyecto, empiece en el [README](../README.md).
El paquete instalable vive en `src/framework_calidad/`; el tablero está en `apps/`.

- **hito3:** reglas de calidad, adquisición, cuarentena y cartas.
- **hito4:** comparación vigente de detectores con validación temporal.
- **hito6:** muestra para revisión externa pendiente.
- **hito5** y **framework_calidad:** accesos compatibles a la implementación actual.
- **Data_Acquisition_and_Understanding:** preparación y línea base OE1.
- **Modeling** y **Evaluation:** experimentos y evaluación de la línea base; H4 es la comparación vigente.

H3/H4 y sus pruebas firmadas conservan rutas y bytes para verificar los manifiestos entregados.
El [mapa de arquitectura](../Docs/guias/arquitectura.md) explica estas dependencias.
