# Framework de calidad de datos de energía

Paquete Python para carga, perfilamiento, reglas, reportes y coordinación de experimentos.
La documentación general está en [Docs/README.md](../Docs/README.md).

Desde `repositorio/`: `poetry --project src sync --with dev`.
La API es instalable; ejecutar las etapas científicas requiere el checkout completo.
