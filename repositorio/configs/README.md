# Configuración

`etapas.toml` es leído por la CLI y contiene tareas, baseline y semillas declaradas.
Las semillas deben coincidir con las constantes de los scripts científicos: editarlas aquí
no modifica el protocolo. Las pruebas verifican esa correspondencia.

Las reglas OE1 versionadas siguen en `z_findings/results/calidad/matriz_oe1.yaml`:
son parte de la evidencia firmada de H3/H4. No se mantiene una segunda copia editable.
Catálogos y metadatos de fuentes: `Data/silver/`. Configuración visual: `.streamlit/config.toml`.
