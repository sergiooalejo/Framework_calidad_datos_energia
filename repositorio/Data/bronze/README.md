# Bronze · fuentes de entrada

Las fuentes seleccionadas y las candidatas en revisión están en [`datos/`](datos/). Se conservan
como copias de entrada. Los archivos en revisión tienen distinta procedencia y todavía no se han
aprobado como fuentes del proyecto. El detalle SSPD es una extracción de una empresa y no el
conjunto completo del portal.

No edites estas copias. Para una nueva descarga registra su origen, fecha y SHA-256.
