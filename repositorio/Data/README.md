# Datos y resultados

- `bronze/`: datos de entrada y capturas externas conservadas.
- `silver/`: datos preparados, catálogos, diccionarios, metadatos y verificaciones.
- `gold/outputs/`: resultados, puntajes, cuarentenas, figuras y muestras.

Los manifiestos permiten verificar procedencia e integridad. Las rutas se mantienen para
conservar su validez. No edite las capturas ni los datos de entrada para corregir alertas;
use los procesos de cuarentena y documente una nueva versión.

La comparación vigente está en `gold/outputs/hito4/`; su protocolo es H4-v2-CV-temporal.
La muestra vigente de revisión es `gold/outputs/hito6/muestra_alertas_h4_v2_epm_50.csv`.
Los resultados anteriores se conservan como evidencia histórica.
